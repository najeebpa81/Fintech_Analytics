# Notebook and reproduction

`Predictive_Model_Loan_Approval.ipynb` is the original exploratory analysis with notebook outputs removed and an updated introductory caution. It includes preprocessing before splitting and test-set threshold exploration, so its evaluation narrative should not be treated as deployment evidence.

For the separately reproduced metrics, run `validate_models.py` from the project root after placing `master_lead_data.csv` and `accepted_sample.csv` in this folder. The CSVs are not redistributed here.
