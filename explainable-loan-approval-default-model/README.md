# Explainable Loan Approval & Default Modeling

This portfolio exercise examines two separate classification tasks using historical/sampled lending records.

**Stage 1 — Initial-decision label:** XGBoost predicts the `initial_decision` field from loan amount, debt-to-income ratio, and employment length. The source master file has 100,000 `Accepted` and 100,000 `Rejected` records. The provenance and decision-label construction need verification; the high ROC-AUC should not be interpreted as independently validated creditworthiness prediction.

**Stage 2 — Historical default outcome:** XGBoost classifies completed accepted loans as fully paid versus charged off/default. Its evaluation covers completed loans only; this selection limits generalization to all newly issued loans. Some predictors (including interest rate and grade) may be determined during underwriting, so the model's intended prediction time must be specified.

## Reproduced results

| Metric | Stage 1 | Stage 2 |
|---|---:|---:|
| Test observations | 28,514 | 20,183 |
| Test ROC-AUC | 0.9651 | 0.7021 |
| Test accuracy at default threshold | 0.9187 | 0.6733 |

Stage 2 test average precision: **0.3682** (positive-class prevalence ~20.0%). Results reproduced using the original XGBoost hyperparameters and stratified splits.

## Local setup

Download and place `master_lead_data.csv` and `accepted_sample.csv` in this project directory. Run `pip install -r requirements.txt`, then `python validate_models.py`. No data files are included here. Dataset provenance and redistribution rights remain unverified.

This is an educational portfolio project, not a deployed credit product or regulatory compliance claim.

## Improved default-risk validation (separate from the historical notebook)

Run `python validate_default_strict.py --accepted-csv /path/to/accepted_sample.csv` after installing requirements. This script fits imputation and categorical encoding on the training partition only; the operating threshold is chosen using the validation partition, and the test partition is evaluated once. The script writes `strict_validation_metrics.json` and a SHAP summary chart for a reproducible 150-row test sample.

On the supplied historical sample (134,549 resolved loans), held-out test ROC-AUC was **0.7019** and average precision **0.3675**. At the validation-selected threshold (**0.4972**), precision was **32.7%** and recall **60.1%**. The historical notebook is preserved as an educational artifact; its original charts are not presented as results of the stricter script.

**Limitations:** random rather than temporal splitting; retrospective completed-loan selection; feature timing for loan terms/grades is unverified; no prospective, fairness, calibration, or regulatory assessment. Raw CSVs are not distributed.
